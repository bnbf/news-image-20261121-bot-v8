Sum up 21 November's world news in one image — a single front page for Saturday 21 November 2026, built for the [make.fun](https://make.fun) bounty `news-image-20261121`.

## What's on the page

- **3 hero leads** — Iran strikes Bahrain as tankers hit in Hormuz; COP31 climate talks run into overtime; deep 6.7 earthquake shakes central Peru
- **12 picture cards**, each with a confidence tag and its source
- **20 ALSO briefs** across 7 regions
- **6-number strip** — 2 | 130+ | 128 | 6.7 | 3 | $58,983
- **UTC timeline** of the day, from the 00:09 Peru quake to COP31 pausing overnight
- **World map with numbered pins** for the pictured stories
- **DATE CHECK footer** — names what is *not* 21 November news (Kyiv's bridges barrage and the missiles in Poland, Wall Street's AI-rout correction, Denmark expelling its Russian attache, Cyclone Akvan's landfall, the EU-UK summit — all Friday 20 Nov) and what had *not yet* happened (COP31 final text, Las Vegas GP race, Liverpool v Man United, India declaring at 720-9)

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR`, or `/output` when unset. Python 3 stdlib only — no dependencies, deterministic output.
